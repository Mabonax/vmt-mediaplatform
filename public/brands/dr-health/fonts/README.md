# Bundled development fonts

Manrope and DM Serif Display were downloaded 22 September 2026 from the official Google Fonts repository. Montserrat and Poppins were added from the user's installed Windows fonts on 23 September 2026 and retain their SIL Open Font License notices. Montserrat and Poppins are the current DrHealth Studio defaults.

- [Manrope source](https://github.com/google/fonts/tree/main/ofl/manrope) — Manrope[wght].ttf and OFL.txt
- [DM Serif Display source](https://github.com/google/fonts/tree/main/ofl/dmserifdisplay) — DMSerifDisplay-Regular.ttf and OFL.txt
- [Montserrat source](https://github.com/google/fonts/tree/main/ofl/montserrat) — Montserrat variable weight and OFL.txt
- [Poppins source](https://github.com/google/fonts/tree/main/ofl/poppins) — Poppins regular, medium, semibold and bold weights and OFL.txt
